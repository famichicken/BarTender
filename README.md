# BarTender 🍸

**Even Realities G2 スマートグラス向け カクテルアシスタント**

冷蔵庫・酒棚の在庫を登録すると、いま作れるカクテルを自動判定。レシピのステップをスマートグラス（G2）に表示し、R1リングと音声でハンズフリーに操作できます。

> 本リポジトリは現在 **設計フェーズ** です。実装に先立ち、仕様を [`docs/SPEC.md`](docs/SPEC.md) にまとめています。まずは仕様のレビュー・合意から進めます。

---

## コンセプト

1. **在庫を登録** — スマホ（コンパニオンWebアプリ）で冷蔵庫・酒棚の中身を登録（手動チェック／音声／バーコード・写真認識）。
2. **作れるカクテルを自動判定** — 在庫から「いま作れる」「あと1つで作れる」「代替材料で作れる」を判定。
3. **グラスでハンズフリー** — 作れるカクテル一覧とレシピのステップをG2に表示。R1リングのジェスチャーと音声コマンドで、両手が塞がっていても手順を進められる。
4. **Favorites & 発見** — お気に入り保存、季節特集・人気・在庫連動のピックアップ。

## 役割分担

| 端末 | 役割 |
|------|------|
| **スマホ（コンパニオンWeb）** | 在庫の登録・編集、レシピ閲覧、Favorites、発見/ピックアップ、設定。公開LP。 |
| **G2グラス** | 作れるカクテル一覧、レシピのステップ表示、R1リング＋音声でのハンズフリー操作。 |

## 主要な決定事項（要約）

- **構成**: スマホで在庫管理 ＋ グラスでレシピ表示・操作
- **デザイン**: バーの世界観・ダーク基調でオシャレに（スマホ/LP）。グラスは視認性優先のミニマル
- **在庫入力**: 手動チェックリスト（3段階: 有/残少/無）→ 音声 → バーコード(できれば)/レシートOCR/手動
- **買い物リスト**: 不足材料をワンタップで登録、チェックリスト化（購入→在庫反映）
- **レシピDB**: 内蔵キュレーション **100種以上**（ジン/ラム/ウイスキー/ウォッカ/サワー/ビール/ノンアル）＋ ユーザー自作。味/感覚（さわやか・マイルド等）・作り方・強さ等で横断分類
- **判定**: 「作れるもの」「あと1つ」「代替材料を許容」
- **グラス操作**: R1リング ＋ 音声コマンド
- **多言語対応**: 日本語 / 英語（将来拡張可能な構造）
- **保存**: ローカル優先のハイブリッド（任意でクラウド同期）
- **LP/発見**: 公開LP ＋ アプリ内ホーム（在庫連動・季節特集・人気ランキング）
- **ダッシュボード/実績**（nice-to-have）: 何をいつ作ったかの記録、統計、バッジで「マイバーの営業記録」

### AI拡張（Addendum v1.0 統合 / `docs/SPEC.md` Part II）

- **コンセプト拡張**: 「正確に作る趣味」→「家にあるもので気軽に1杯」。初心者ハードルの解消
- **ゆる版レシピ**: 「〜風」名称・目分量・軽め/標準/濃いめ・代用前提（材料3つ/工程3〜5）
- **AI液面ガイド（AI-11）**: グラス写真に投入ライン（赤=ベース/黄=酸味/青=割材/灰=氷）を重畳。G2は短文ナビ
- **透明シェイカー補助（AI-12）**: 目盛り/ラインで投入量を案内（推奨オプション道具）
- **AI提案/代用/味調整/好み学習**: 在庫・好み・履歴から初心者向けの一杯と次回配合を提案
- **AIは BYOK**: ユーザーが自分のAPIキーを設定して利用（未入力時はローカル機能のみ）
- **SNS/コミュニティ**: 後回し（現スコープ外・将来）
- **⚠️ 安全・法務（必須）**: 生年月日による年齢確認・未成年禁止・飲酒運転防止・ABV注意・過度飲酒の不助長・低/ノンアル導線
